# Security policy

## Reporting a vulnerability

Report a vulnerability privately through GitHub: on the repository page open **Security** > **Report a vulnerability**
(private vulnerability reporting). Please do not open a public issue or pull request for it.

Include the affected version, the steps to reproduce it and the impact you see. You get an answer as soon as a
maintainer has read the report; a confirmed issue is fixed on `release/next` and published with the next release.

## Supported versions

The latest release (see the [releases page](https://github.com/GravionLabs/poimen/releases)) is supported.
