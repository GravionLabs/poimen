# AGENTS.md

Guidance for humans and coding agents working in this repository. Generated text (docs, issues, commits, code) is written in US English.

## Architecture

- `src-tauri/src/herdr.rs`: socket API client (NDJSON over the Unix socket); `SUPPORTED_PROTOCOL` (the protocol poimen is written for) lives here. Requests use short-lived connections; subscriptions keep theirs.
- `src-tauri/src/backend.rs`: `Backend` trait with `ensure_running` and the herdr implementation: ping the socket, else start a detached `herdr server` (own process group, stdio null, never waited on, never stopped by poimen) and wait for the socket and the supported protocol; behind the `herdr.autoStart` setting and the `ensure_backend` command. `gui_path.rs` is the login-shell `PATH` of a GUI app (shared with `plugin_view.rs`). Tests use a fake `Runner`; never start or stop a server in a test.
- `src-tauri/src/watch.rs`: one long-lived `events.subscribe`. `pane.agent_status_changed` needs a `pane_id`, and herdr rejects the whole subscription when a referenced pane is gone, so the watcher resubscribes on pane-set changes.
- `src-tauri/src/settings.rs`: user settings (`~/.config/poimen/config.json`, optional Ghostty config); `get_settings` command plus a polling watcher emitting `settings`. Preferences only, never UI state; frontend side is `core/settings.ts`.
- `src-tauri/src/schemes.rs`: user color schemes (WezTerm TOML in `~/.config/poimen/themes/`); `get_color_schemes` command plus a polling watcher emitting `color-schemes`; frontend side is `core/user-schemes.ts`.
- `src-tauri/src/github.rs`: shared GitHub client over the `gh` CLI ([ADR 0005](docs/adr/0005-github-views-and-agent-harnesses.md)): `repo_of(dir)` (GitHub `origin` only), `Client::rest` (`gh api --include`, ETag revalidation, body cached 30 s per exact path in the app cache dir) and `Client::graphql` (30 s in-memory cache per query and variables); errors serialize as `GhError` (`gh-missing`, `not-logged-in`, `offline`, `rate-limited`, `not-found`, `other`). `gh` is resolved through `gui_path.rs`; a `Runner` trait fakes the child process in tests (no network). Never logs tokens or headers.
- `src-tauri/src/github.rs`: shared `gh` client (argv, login-shell `PATH`, 60 s timeout, REST with ETag disk cache, GraphQL in-memory cache of 30 s, `GhError`). `src-tauri/src/github_pulls.rs`: `github_pulls(dirs)` (one GraphQL query per repository from `git::repo_roots`, `viewer` once; fixture `fixtures/github-pulls.json`). Frontend: `src/app/github/` (`pulls.ts` service with filters and selection signal, `github-view`); tab kind `github` in `core/editor-tabs.ts`.
- `src-tauri/src/plugin_view.rs`: native views for herdr plugins (ADR 0004, superseded by [ADR 0005](docs/adr/0005-github-views-and-agent-harnesses.md); #234 removes it). Reads the `data` action of a plugin from `plugin.list`, runs it itself (login-shell `PATH`, timeout) and parses the versioned envelope (`fixtures/deliver-board-data-v1.json`); the `deliver_board` command returns one board per repository (from `git.rs` `repo_roots`). `herdr.rs` hides the `data` action from the action list. Frontend: `core/deliver-board.ts` and `src/app/deliver-board/`.
- `src-tauri/src/transcripts.rs`: read-only Claude Code transcripts (`~/.claude/projects`): path resolution, tolerant JSONL parsing (unknown entry types and fields are skipped), running/done detection, a `Tailer` per file and a `notify` watch (`watch_dir`) emitting `subagents` events; `subagents_watch`/`subagents_unwatch` commands (agent, session and cwd come from `herdr::parse_agent_session`). `src-tauri/src/copilot.rs` is the second transcript source: GitHub Copilot CLI's `~/.copilot/session-state/<session>/events.jsonl` (main session and subagents in one file, fixture `fixtures/copilot-events.jsonl`) mapped onto the same wire types (`task` as `Agent`, `skill` as `Skill`), so the frontend has no Copilot-specific code; which agents are followed is `supportsFlow`/`flowSession` in `core/herdr.ts`. Frontend side: `core/transcripts.ts` (wire types, `transcriptItems` model reusable by other panel tabs, `Subagents` service) and `src/app/bottom-panel/` (tabs, subagent dropdown, Output tab; state in `core/ui-state.ts`). The Flow tab: the tracker also emits a `main` update (Skill/Agent calls of the main transcript with results, count of other tool calls); `core/flow-graph.ts` (pure: nodes and edges from agents, their entries and the main snapshot; nesting by tool use id, else `spawnDepth`) and `core/flow-layout.ts` (`@dagrejs/dagre`) feed `bottom-panel/flow-view.ts` (`@foblex/flow`, lazy via `@defer`). Both libraries are pinned exactly. Watches are keyed by follower (`subagents_watch { key, paneId }`, events carry the `key`): the root `Subagents` follows the panel's pane, a flow editor tab (`poimen:flow:<paneId>`, `src/app/flow-tab/`) provides its own instance for its pane and stops the watch when it is destroyed.
- `src-tauri/src/stream.rs`: live terminals by spawning `herdr terminal session observe|control`. Use this public CLI contract; do not reimplement herdr's internal binary client protocol.
- `site/`: the public site on GitHub Pages (`https://gravionlabs.github.io/poimen/`), VitePress, self-contained (own npm lockfile, excluded from the app's eslint and prettier). The ADRs of `docs/adr/` are not published there; a dead link fails `npm run build`. Download links are resolved client-side from the latest release (`site/downloads.ts`, tested). Workflow `.github/workflows/pages.yml`: dry-run build on pull requests touching `site/`, deploy on push to `main` while the repository variable `DEPLOY_PAGES` is `true`.
- `src/`: Angular 22 (standalone components, signals) on helix-ui, built with `@angular/build` (`angular.json`), tested with Vitest. `src/app/core/` is the Tauri bridge and state: `tauri.ts` (the only `invoke`/`listen` caller), `herdr.ts` (wire types, pure helpers), `herdr-store.ts` (snapshot signals, debounced re-read), `terminal-stream.ts` (routes `terminal` records by session id). `src/app/terminal-view/` wraps xterm.js for the active editor tab (`core/editor-tabs.ts` holds tabs, preview/pinned and mode; `src/app/ui/helix-candidates/tab-bar/` is the generic tab bar, a helix-ui candidate); `src/app/sidebar/` shows the spaces tree (`hx-tree`; `src-tauri/src/git.rs` answers the read-only `repo_info` command with branch and worktree per directory); `src/app/activity-bar/` is the view rail; `src/app/notifications/` is the notification center view over `core/notification-center.ts` (in-memory list fed by `Attention` status changes); `core/ui-state.ts` holds persisted UI state (sidebar width/collapsed), never pane state. `core/attention.ts` keeps in-memory UI marks derived from herdr statuses: a pane that turns blocked while not viewed rings on its tab and sidebar row, one that turns done while not viewed counts as unread (workspace rows sum their panes); viewing the tab (active tab of a group) clears both.

## Rules

- **herdr owns state.** poimen never stores pane state of its own; snapshots from herdr are authoritative and events only invalidate them.
- **Non-destructive.** Closing a view or the app releases controllers and kills only the CLI child processes, never herdr panes. Taking over a controller requires an explicit user action.
- **Tests stay read-only.** Live tests (`#[ignore]`) may list and observe, never control, send input or create panes in the user's session.
- **Protocol drift.** herdr's API protocol is versioned (22 at the time of the spike). Keep all wire shapes in `herdr.rs` and `stream.rs`, each with a parsing test.

## Decisions

- Frontend stack: Angular 22 and helix-ui, and when a component goes to helix-ui ([ADR 0001](docs/adr/0001-frontend-stack.md)).
- Color schemes: bundled and imported schemes, a derived chrome and the `colorSchema` setting ([ADR 0002](docs/adr/0002-color-schemes.md)).
- Own terminal backend `poimen-server` next to herdr, agent status from Claude Code and Copilot hooks (proposed, [ADR 0003](docs/adr/0003-own-terminal-backend-without-herdr.md)).
- Native views for herdr plugins: `deliver-board` and `review-popup` get one, through a `data` action that prints versioned JSON; `deliver-view` stays an agent view ([ADR 0004](docs/adr/0004-native-views-for-herdr-plugins.md), superseded by [ADR 0005](docs/adr/0005-github-views-and-agent-harnesses.md)).
- GitHub views and agent harnesses native in poimen; replaces the plugin views of ADR 0004 (accepted, [ADR 0005](docs/adr/0005-github-views-and-agent-harnesses.md)).

## CI and releases

- `.github/workflows/ci.yml` checks the frontend and the Tauri crate (with the Linux system libraries) through GravionLabs/ci `@v1`; its always-running `ci` gate job (green when the checks passed or no app files changed) and `pr-checks / PR checks` (`pr-checks.yml`: readiness, Conventional Commit title) are the checks required on `main` and `release/**`.
- Reusable workflows and actions of GravionLabs/ci are referenced at `@v1`, never `@main` or a SHA.
- Work is integrated on `release/next`: every PBI branch is cut from it and its PR targets it (squash); `main` only receives the release PR (merge commit). `release.yml` versions with GitVersion, writes `CHANGELOG.md` with git-cliff and tags `v<version>`. README "Releases" has the rules.
