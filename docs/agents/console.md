# Console (`poimen` TUI and CLI)

`poimen-console`: TUI, CLI, attach and MCP. Read before you touch these areas. Notes on a change go here, not in `AGENTS.md`.

- `src-tauri/crates/poimen-console/src/tui/attention.rs` (#518): attention of the TUI, the rules of `core/attention.ts` as pure code (`Attention`: blocked while not viewed rings, done counts as unread, viewing clears; `Log`: the notification list, prefix key `N` (`console.keys.notifications`), Enter focuses the terminal). No system notifications (#676). Status comes from the hook-reported `agent` of the terminals; the run rule of #540 (`host["poimen.terminal"]`) is not applied in the TUI yet.
- `src-tauri/crates/poimen-console/`: console client of ADR 0006, binary `poimen` (the app is `poimen-app`). `poimen attach [--control [--takeover]] <terminal>` (#176): `cli.rs` (pure argument parsing of every command), `keys.rs` (detach `Ctrl+B d`, `Ctrl+B Ctrl+B` sends one, UTF-8 joining), `tty.rs` (`Terminal` trait, crossterm `LocalTerminal`, `RawGuard` restores raw mode on drop), `session.rs` (`run`: `Client::attach`, snapshot then stream to any `Write`, controller input and window-size polling through `AttachmentWriter`, `RESET` written at the end; signals SIGTERM/SIGHUP/SIGINT set a stop flag). CLI (#175): `commands.rs` (`run(client, Request, wait, out)`: `ls [--json]`, `status <terminal> [--json]`, `new <space> [--name n] [-- cmd..]` (space by id or exact name, prints the terminal id), `send <terminal> [--enter] <text..>`, `prompt <terminal> <text..>` = `Client::prompt_agent`, refused with exit 1 while the agent is working or blocked or absent); `poimen mcp` (#613, ADR 0012, `mcp.rs`): stdio MCP server (JSON-RPC, a message per line, ends when stdin closes) with the read tools `list_spaces`, `list_terminals` (compact), `get_terminal` (#1153: `terminal`; unknown terminal is a tool error), `read_terminal` (#1154: `terminal`, `lines?` default 50, max 500; an observer attach, its snapshot replayed into a private `alacritty_terminal` (`mcp/screen.rs`) and read as text: no escapes, wrapped rows joined, wide cells once, trailing blank lines dropped; `running`, `state`, `lines`, `text`, and a `note` when cut to 64 KiB; no input, no control, no consent for another space; tests `tests/mcp_read_terminal.rs`, a file of its own because `tests/mcp.rs` is at the 800 line ratchet), `whoami` (`POIMEN_TERMINAL_ID`; `{in_poimen: false}` outside) and `list_runs` (`repository` dir; core `Reducer` over `<common-dir>/.agents/events/*.jsonl`, one-shot, no `events` rows; #1142: `status` `running`/`finished`/`needs-you`, `limit` default 20, newest first by `updated`, `compact` drops `finished` and `links`) and `get_events` (`repository`, `run`, `after?`, `type?`, `limit?` default 100 max 1000: the raw events with `seq > after`, `more`; terminal gone/closed ends it) and `read_agent` (`agent.transcript` with `restart`, `main.last_message`) (#979); `mcp/report.rs` is `report_done` (#980: `terminal.report_done`, then `run.finished` appended to the caller's running run in `<common-dir>/.agents/events` or a new `agent-<terminal>-<secs>` run; `PREAMBLE` appended by `start_agent`; `with_report` adds the stored report to `wait_agent`), the server side is `poimen-server/src/reports.rs` (store, one typed line to an idle starter, 1 s sweeper); write tools `stop_terminal` (#1183: `mcp/stop.rs`; `terminal`, `mode?` `interrupt` = `terminal.input` `\x03` then polls up to 3 s for `exited`, or `close` = `terminal.close`, refused with a running agent unless `force`; `outcome` `ended`/`running`/`gone`; `authorize` with `AgentWriteAction::StopTerminal` on the terminal's space; tests `tests/mcp_stop.rs`), `write_terminal` (#1184: `mcp/write.rs`; `terminal`, `text`, `enter?` appends `\r`; refused with an agent, an exited terminal, a control character other than `\n`/`\t`; no confirmation only when `started_by` is the caller, else `authorize(.., always_ask)` with `AgentWriteAction::WriteTerminal` showing the text; tests `tests/mcp_write_terminal.rs`), `start_shell` (#1181: `mcp/shell.rs`; `command` argv, `cwd?`, `name?`, `space?`, `env?`; a `terminal.create` with `command`, an exited terminal stays listed; `authorize` with `AgentWriteAction::StartShell`, tests `tests/mcp_shell.rs`), `start_agent`/`prompt_agent` (#615; `start_agent` `worktree: {issue, title?, mode?}` or `{branch}` (#981) makes the task worktree (`worktree.create` for an issue, `worktree::ensure` for a branch, an existing one is reused unchanged) and a new space on it, always confirmed (`authorize(.., always_ask)`) before anything is made; [y/N]`; `taken_over` falls back to observing; the PTY follows the pane size; never attaches to `POIMEN_TERMINAL_ID`; detach sends `terminal.detach` only, never closes a terminal or stops the server). Tests: `tests/tui_grid.rs` (fixtures `tests/fixtures/tui/<case>.ansi` + `.txt`, all OSs), `tests/tui.rs` (in-process server, `TestBackend` mirror, Unix only).
- `src-tauri/crates/poimen-console/src/tui/`: the TUI (ADR 0006). `tree.rs` is pure (split tree to leaf rectangles and one-cell borders, `neighbor`, `resize`), `input.rs` routes the prefix keys (`Routed`), `sidebar.rs` holds the `Model` (`tab_of`, `space_tabs`, `focus_target`, `remote_focus`, `after_loss`), `mod.rs` keeps one `Pane` (attachment and grid) per visible leaf, only the selected one as controller (`sync_panes`), changes only through `tab.*` requests and follows events (`follow_server`). Command palette (#517): `palette.rs` is pure state and drawing (`items`, `filter`, `complete_dirs`, `Palette::key` giving `Out::Close` or a `Command`), `actions.rs` is what a command does (`create_space` with the `trust_required` handshake and `answered` to send it again, `run_entry` behind `trust::gate` like the app's `project_run`, `task_setup`, `prepare_task` = `task_start::plan` + `worktree::ensure` + the `SpaceCreate` with `command`, `start_prepared`, issues through `Options.issues`, a function that tests replace); `mod.rs` holds the pending request while the trust question is open and runs issue reading and task start on threads. Tests: unit in each file, `tests/tui.rs` and `tests/tui_palette.rs` against an in-process server on a temp socket and a temp home.
- `poimen doctor [--json] [--bundle <file>]` (#972): `doctor.rs` is pure (`report(&Inputs, paths) -> Report`, exit code 1 only for an `error`), `doctor/collect.rs` reads the facts (`Client::ping`, `state_file_path`, `poimen-server integration status <kind>` and `poimen-pty-host --version` of the binaries next to the console through the `Runner` trait, CLIs and `gh`/`git` with `gui_path::resolve_program` on the login-shell `PATH`), `doctor/bundle.rs` writes the bundle (`shape` keeps ids and counts only, log tails of 200 KiB with the state directory and home replaced, `create_new` with mode 0600). `server.json.bak` is a finding only when `server.json` is missing or older (every save leaves one). Tests: `tests/doctor.rs` (in-process server, temp `PATH` of fake programs).
- Shared session operation (#744, ADR 0016): `poimen_client::agent` (`agent/session.rs`) holds what the MCP write tools, the later `poimen session run` and the host module of a script share. `run_session(client, ctx, request, on_event)` resolves the harness from the user's `config.json` (`harnesses_of`; a project config contributes none, so an untrusted one cannot add templates; only ids in `HOOK_KINDS` run, others are refused as "no hooks"), checks the permission on the space id the server resolved (`authorize_write`, ADR 0012: own space free, any other through `agent.confirm`, refused without app or caller), creates the terminal (`<run id> <title>` tab name, `AGENT_EVENTS_RUN`, `Terminal.run`/`task`), starts the argv per element (`promptArgs`, else the prompt is typed with `prompt_agent` after `SessionStart`) and waits with `watch_agent` (event subscription, no polling; `blocked` does not end it). `SessionEvent` reaches the callback; errors are `SessionError::{StartFailed, Ended, ConnectionLost, PermissionRefused}` for the CLI's exit codes. The MCP `authorize`, `harnesses_of` and `wait_agent` call `authorize_write`, `harnesses_of` and `watch_agent`. No `report_done` preamble in a session. `placement` is passed on, the server keeps none yet. Tests: `poimen-console/tests/session.rs` (in-process server, fake harness script, hooks reported by the test).
