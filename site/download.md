# Download

The latest release of poimen, for 64-bit systems. The buttons resolve the installers of the newest release when the page opens; if that does not work, they lead to the page of the latest release.

<Downloads />

- Linux x64: `.AppImage` (runs anywhere), `.deb` (Debian, Ubuntu) and `.rpm` (Fedora, openSUSE).
- macOS: Apple Silicon (arm64) `.dmg`. There is no Intel build.
- Windows x64: `.exe` setup and `.msi`.

poimen needs [herdr](https://herdr.dev) 0.9.5 or newer. The installers are **not code-signed** yet ([#45](https://github.com/GravionLabs/poimen/issues/45)), so macOS and Windows warn on the first start. [How to open the app](/guide/installation).
